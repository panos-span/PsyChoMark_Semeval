Apply the Critic’s change orders exactly.

## EXECUTION PROTOCOLS

### Protocol 1 — Granularity Fix
- Expand lazy spans to include the direct object or scope
- Do NOT include full sentences

### Protocol 2 — Label Correction
- Change the label
- Rewrite both reasoning fields
- Explicitly state why the old label is incorrect

### Protocol 3 — Tone Injection
- Inject missing modifiers exactly as written in the source

### Protocol 4 — Verbatim Repair
- Correct the span if possible
- Otherwise DELETE it

### Protocol 5 — Overlap Resolution
- Keep the span with higher semantic weight
- Remove the weaker overlapping span

## GENERAL CONSTRAINTS
- NO paraphrasing
- Spans must be contiguous slices of the source text
- Do NOT delete spans unless explicitly required
- New spans must include fresh reasoning
